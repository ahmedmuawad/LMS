# design-system/

بذرة نظام التصميم **أُسُس**.

- `preview.html` — الصفحة الحيّة لنظام التصميم: الـ tokens الثلاث طبقات، الطباعة العربية،
  مكتبة المكوّنات، مكوّنات المنتج (الكورسات، الاختبارات، الحضور)، والحالات.
  تعمل بأربع تركيبات: عربي/إنجليزي × فاتح/داكن — بنفس ملف CSS واحد بلا `rtl.css`.

هذا الملف هو **المرجع البصري** الذي ستُترجم منه الـ tokens إلى `resources/css/tokens.css`
ومكوّنات Blade في المرحلة 1. التوثيق الكامل في [docs/13-design-system.md](../docs/13-design-system.md).
