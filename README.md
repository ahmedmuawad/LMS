# منصة التعلم والتجارة — بديل WPLMS بلغة Laravel

مستودع التخطيط والتوثيق لمشروع تحويل موقع قائم على قالب **WPLMS** (WordPress) إلى
منصة مبرمجة بالكامل بـ **Laravel**، تجمع:

**بيع الكورسات** (LMS كامل) · **بيع الخدمات** (باقات وحجوزات) · **بيع المنتجات** (رقمية ومادية) ·
**مدونة** · **Page Builder** · **لوحة تحكم شاملة** — **ثنائية اللغة (عربي/إنجليزي)** بالكامل.

> **الحالة:** المرحلة 0 (التوثيق والتخطيط) — لا يوجد كود تطبيق بعد.

---

## 🧰 اللغات والتقنيات المستخدمة

### لغات البرمجة
| اللغة | أين تُستخدم |
|-------|-------------|
| **PHP 8.4** | الخلفية بالكامل (Laravel) — ~65% من الكود |
| **TypeScript / JavaScript** | الواجهة التفاعلية (Vue 3)، مشغّل الكورس، محرر الصفحات — ~25% |
| **SQL** | مخطط قاعدة البيانات، الاستعلامات المعقّدة، سكربتات الترحيل |
| **HTML5 + CSS3** | القوالب (Blade) والتنسيق (Tailwind) — RTL/LTR |
| **Blade** | قوالب Laravel ولوحة الإدارة |
| **Bash** | سكربتات النشر والنسخ الاحتياطي والصيانة |
| **YAML** | إعدادات CI/CD وDocker |

### التقنيات الأساسية
**Laravel 13** · **Filament v4** (الإدارة) · **Inertia 2 + Vue 3 + Tailwind 4 مع SSR** (الواجهة) ·
**MySQL 8.4** · **Redis + Horizon** · **Meilisearch** (بحث عربي) · **Laravel Reverb** (WebSockets) ·
**Octane + FrankenPHP** (الأداء) · **Bunny Stream** (الفيديو) · **Paymob/Fawry/Stripe** (الدفع) ·
**Pest 3 + Larastan + Pint** (الجودة) · **Docker + GitHub Actions** (CI/CD)

التفاصيل الكاملة ومبررات كل اختيار: [وثيقة التقنيات](docs/02-tech-stack.md)

## ⚡ الملخص التنفيذي

1. **Laravel 13 + PHP 8.4** بمعمارية **Modular Monolith** — 35 موديولاً (بلجن داخلي) قابلاً للتفعيل/التعطيل، لكل منها صفحة إعدادات كاملة.
2. **Filament v4** للإدارة (يختصر 60–70% من شاشات الإدارة) + **Inertia/Vue 3 مع SSR** للواجهة.
3. **ثنائي اللغة بالتصميم:** ترجمة الواجهة + ترجمة المحتوى (JSON) + hreflang + RTL/LTR + محرّر ترجمات من اللوحة.
4. **الأداء والسيو أولوية أولى:** ميزانية أداء مُلزِمة في CI (LCP ≤ 2s · INP ≤ 150ms · TTFB ≤ 200ms) + **بلجن سيو داخلي** كامل (Schema، خرائط، 301، Search Console، llms.txt).
5. **Page Builder بالبلوكات** (JSON + مكوّنات حقيقية) لا Canvas حر — أنظف وأسرع وأدق في RTL.
6. **محرك تجارة موحّد** يبيع كورساً/خدمة/منتجاً/باقة/اشتراكاً من نفس السلة.
7. **دفع محلي كامل:** Paymob + Fawry + تحويل بنكي + محفظة، ودولي عبر Stripe/PayPal، خلف واجهة موحّدة.
8. **الترحيل من WordPress** عبر ETL قابل للتكرار، مع **الحفاظ على كلمات المرور** وخريطة 301 كاملة.
9. **المنهجية:** كل مرحلة تمر بـ 7 خطوات و5 بوابات إقفال، مع مراجعة بعين مبرمج آخر وعين صاحب المشروع.
10. **المدة:** MVP في **16–18 أسبوعاً** (موصى به)، أو النطاق الكامل في **25–29 أسبوعاً** بفريق 5–6 أشخاص.
