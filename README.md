# منصة التعلم والتجارة — بديل WPLMS بلغة Laravel

مستودع التخطيط والتوثيق لمشروع تحويل موقع قائم على قالب **WPLMS** (WordPress) إلى
منصة مبرمجة بالكامل بـ **Laravel**، تجمع:

**بيع الكورسات** (LMS كامل) · **بيع الخدمات** (باقات وحجوزات) · **بيع المنتجات** (رقمية ومادية) ·
**مدونة** · **Page Builder** · **لوحة تحكم شاملة** — **ثنائية اللغة (عربي/إنجليزي)** بالكامل.

> **الحالة:** المرحلة 0 (التوثيق والتخطيط) — لا يوجد كود تطبيق بعد.

---

## 🧰 اللغات والتقنيات المستخدمة

### لغات البرمجة
| اللغة | أين تُستخدم |
|-------|-------------|
| **PHP 8.4** | الخلفية بالكامل (Laravel) — ~65% من الكود |
| **TypeScript / JavaScript** | الواجهة التفاعلية (Vue 3)، مشغّل الكورس، محرر الصفحات — ~25% |
| **SQL** | مخطط قاعدة البيانات، الاستعلامات المعقّدة، سكربتات الترحيل |
| **HTML5 + CSS3** | القوالب (Blade) والتنسيق (Tailwind) — RTL/LTR |
| **Blade** | قوالب Laravel ولوحة الإدارة |
| **Bash** | سكربتات النشر والنسخ الاحتياطي والصيانة |
| **YAML** | إعدادات CI/CD وDocker |

### التقنيات الأساسية
**Laravel 13** · **Blade + Alpine.js + Vite 7 + Tailwind 4** (الواجهة واللوحات) · **جزر Vue 3** للشاشات المعقّدة ·
**نواة إدارة مخصّصة مدفوعة بالـ Schema** (لا لوحات جاهزة) · **stancl/tenancy** (قاعدة ماستر + قاعدة لكل مشترك) ·
**MySQL 8.4** · **Redis + Horizon** · **Meilisearch** (بحث عربي) · **Laravel Reverb** (WebSockets) ·
**Octane + FrankenPHP** (الأداء) · **Bunny Stream** (الفيديو) · **Paymob/Fawry/Stripe** (الدفع) ·
**Pest 3 + Larastan + Pint** (الجودة) · **Docker + GitHub Actions** (CI/CD)

التفاصيل الكاملة ومبررات كل اختيار: [وثيقة التقنيات](docs/02-tech-stack.md)

## ⚡ الملخص التنفيذي

1. **منتج SaaS متعدد المستأجرين** — يُباع بالاشتراك لمدرّسين وأكاديميات وسناتر، **في عدة دول وبعدة عملات**.
2. **العزل:** قاعدة بيانات ماستر + **قاعدة مستقلة لكل مشترك** (`stancl/tenancy`) — عزل مطلق وتصدير كامل.
3. **٤ أنماط منصة** (مدرّس فردي · متعدد المدرّسين · سنتر تعليمي · شامل) × ٣ أنواع تقديم (مسجّل · مباشر · مدمج)، يختارها المشترك في **معالج التهيئة** فتُبنى لوحته وثيمه وموديولاته على أساسها.
4. **كل خيار مبني بالكامل** — التحكم من الإعدادات وطبقة **الصلاحيات (Entitlements)**: مزايا · حدود · حصص استهلاك.
5. **Laravel 13 + Blade + Alpine + Vite + Tailwind 4**، وجزر Vue في ٧ شاشات معقّدة فقط، فوق **Octane/FrankenPHP**.
6. **لوحة إدارة مخصّصة بالكامل** بنواة مدفوعة بالـ Schema — لا Filament ولا أي لوحة جاهزة.
7. **نظام التصميم أُسُس أولاً** — tokens من ٣ طبقات و٦٥ مكوّناً، ثنائي اللغة وفاتح/داكن، بحوكمة آلية في CI.
8. **الأداء والسيو بوابة CI** (LCP ≤ 2s · INP ≤ 150ms · TTFB ≤ 200ms) + **بلجن سيو داخلي** كامل لكل مستأجر.
9. **إدارة السنتر وحدة كاملة** — أكبر فارق تنافسي: لا منافس يربط السنتر الحضوري بمنصة بيع أونلاين.
10. **٩ بوابات دفع + أكواد شحن**، وضرائب وفوترة إلكترونية (ETA · ZATCA) لكل دولة.
11. **٢٨ ميزة** استُخرجت من دراسة ٢٥ منافساً ودخلت النطاق (أكواد الشحن · منع لقطة الشاشة · QR على المذكرات · المراجعة الذكية · الفيديو التفاعلي · SCORM/H5P · التلعيب · تطبيق باسم المشترك …).
12. **المدة:** إطلاق تجاري بعد **~36 أسبوعاً**، والنطاق الكامل **47 أسبوعاً** بفريق 5–6.
