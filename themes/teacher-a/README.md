# themes/teacher-a — «لوح الشرح» (اتجاه أ)

ثيم موقع المدرّس المشترك. مبنيّ من تصميم `Teacher Theme A.dc.html`
(Claude Design)، وموجَّه للنمطين `teacher` و`solo`.

## الفكرة

لوحٌ داكن كامل العرض (`--sem-spot`) بخلفية شبكة كرّاسة يفتح الصفحة
ويقفلها، وبينهما أسطحٌ فاتحة. الترتيب يتبع ترتيب أسئلة الزائر:

| القسم | يُعرض متى |
|-------|-----------|
| الواجهة (اللوح) | دائماً |
| شريط الأرقام | إن وُجد رقمان صادقان فأكثر |
| الكورسات | `homepage.show_courses` وكورسات منشورة |
| المجموعات | موديول `center` ومجموعات حالتها `open` |
| المعاينة المجانية | كورس منشور فيه عنصر `is_preview` |
| عن المدرّس | `homepage.about` مكتوب |
| آراء الطلبة | تقييمات معتمَدة بأربع نجوم فأكثر ولها نصّ |
| لوليّ الأمر | موديول `parent-portal` |
| طرق الدفع | بوابة واحدة على الأقل مهيّأة فعلاً |

**لا قسم يُختلَق محتواه.** ما لا يجد ما يملؤه يختفي: قسمٌ فارغ أسوأ
من غيابه، ورقمٌ مُختلَق أسوأ منهما.

## ما يقرؤه من الإعدادات

يقرأ كل ما تقرؤه الصفحة الرئيسية في النواة (`homepage.headline` ·
`subheadline` · `hero_image` · `cta_label` · `cta_url` · `point_1..3` ·
`about` · `phone` · `whatsapp` · `show_*`)، ويزيد عليها — وكلّها
اختيارية، وغيابها لا يكسر شيئاً:

| المفتاح | ما يفعله |
|---------|----------|
| `homepage.stat_students` | يحلّ محلّ العدّ الآلي للطلبة في شريط الأرقام |
| `homepage.stat_years` | سنوات الخبرة — لا مصدر لها غير المدرّس نفسه |
| `homepage.highlight_value` | رقم البطاقة العائمة فوق صورة الواجهة (مثلاً `٪٩٤`) |
| `homepage.highlight_label` | عنوان البطاقة (افتراضياً «نتيجة آخر دفعة») |
| `homepage.highlight_note` | سطر صغير تحته (الصف والسنة مثلاً) |
| `homepage.about_title` | عنوان قسم «عن المدرّس» |
| `homepage.about_image` | صورة القسم — وإلا فصورة الواجهة |
| `homepage.credential_1` + `_note` | بطاقة مؤهّل (الدرجة والجهة) |
| `homepage.credential_2` + `_note` | بطاقة مؤهّل ثانية |

البطاقة العائمة لا تظهر إلا بـ`highlight_value`: رقمُ نجاحٍ مكتوبٌ في
القالب كذبٌ على كل مدرّس لم يكتبه.

## ما لا يفعله

- **لا لون حرفيّاً ولا token من الطبقة الأولى.** كل شيء من الطبقة
  الدلالية، فتخصيص المشترك (اللون الأساسي والتمييز ونصف القطر) يسري
  على الثيم بلا سطر إضافي.
- **لا خطّ خارجيّاً.** التصميم الأصلي يجلب `IBM Plex Sans Arabic` من
  Google Fonts؛ هنا يُستخدم خطّ المنصة المستضاف ذاتياً (وثيقة 13.3).
- **لا أرقام هندية.** التصميم يعرض `١٨٤٠`؛ المنصة كلها تعرض `1840`.
  توحيدُ ذلك إعدادٌ عامّ (`appearance.numerals`) لا شأن للثيم به.
