# 13 — نظام التصميم (Design System)

> **القاعدة الحاكمة:** لا تُكتب شاشة واحدة قبل اكتمال نظام التصميم.
> أي مكوّن غير موجود في النظام = **لا يُستخدم**؛ يُضاف للنظام أولاً ثم يُستخدم.
> هذا هو الفرق الوحيد بين منتج يبدو محترماً وموحّداً، ومنتج يبدو مجمّعاً من قطع.

---

## 13.1 معمارية الـ Tokens — ٣ طبقات

```
الطبقة 1: Primitive  ← قيم خام، لا تُستخدم في المكوّنات أبداً
  --blue-600: #2563eb        --space-4: 1rem
  --gray-900: #111827        --text-lg: 1.125rem

الطبقة 2: Semantic   ← المعنى، وهي المستخدمة في 95% من الكود
  --color-primary: var(--blue-600)
  --color-surface: var(--white)
  --color-text-muted: var(--gray-500)
  --color-danger: var(--red-600)

الطبقة 3: Component  ← تخصيص مكوّن بعينه عند الحاجة فقط
  --btn-height-md: 2.5rem
  --card-radius: var(--radius-lg)
```

**لماذا ٣ طبقات؟** لأن **ثيم المستأجر يغيّر الطبقة الثانية فقط**.
يبدّل `--color-primary` فيتغيّر كل شيء في المنصة تلقائياً — أزرار، روابط، مؤشرات، رسوم بيانية، حالات التركيز — بلا لمس سطر واحد من كود المكوّنات.

### قاعدة صارمة
```css
/* ❌ ممنوع منعاً باتاً */
.btn { background: #2563eb; }
.btn { background: var(--blue-600); }

/* ✅ الصحيح */
.btn { background: var(--color-primary); }
```
يُفرض آلياً بقاعدة Stylelint ترفض أي لون حرفي أو أي token من الطبقة الأولى داخل مكوّن.

## 13.2 الألوان

### المقاييس الأساسية
كل لون بـ ١١ درجة (50 → 950): **Brand · Gray · Red · Amber · Green · Blue · Violet**

### الـ Tokens الدلالية
```css
:root {
  /* الأسطح */
  --color-bg:              /* خلفية الصفحة */
  --color-surface:         /* البطاقات واللوحات */
  --color-surface-raised:  /* القوائم المنسدلة والنوافذ */
  --color-surface-sunken:  /* رؤوس الجداول والمناطق الغائرة */
  --color-overlay:         /* طبقة تعتيم النوافذ */

  /* النص */
  --color-text:            /* النص الأساسي */
  --color-text-muted:      /* ثانوي */
  --color-text-subtle:     /* تلميحات */
  --color-text-inverse:    /* على خلفية داكنة */

  /* الحدود */
  --color-border:  --color-border-strong:  --color-border-focus:

  /* الأدوار */
  --color-primary / -hover / -active / -subtle / -on
  --color-success --color-warning --color-danger --color-info  (+ -subtle / -on)

  /* التعليم — خاصة بمنتجنا */
  --color-progress   /* شريط التقدّم */
  --color-completed  /* درس مكتمل */
  --color-locked     /* درس مقفول */
  --color-live       /* بث مباشر الآن */
  --color-attended --color-absent --color-late   /* الحضور في السنتر */
  --color-paid --color-due --color-overdue        /* المالية */
}
```

### الوضع الداكن
يُعاد تعريف **الطبقة الدلالية فقط** تحت `[data-theme="dark"]` و`@media (prefers-color-scheme: dark)`.
لا يُعاد تعريف أي مكوّن. الوضع الداكن مدعوم في **كل** شاشة بلا استثناء.

### التباين (إلزامي)
| العنصر | الحد الأدنى |
|--------|-------------|
| نص عادي | 4.5:1 |
| نص كبير (≥24px أو ≥18.66px عريض) | 3:1 |
| حدود عناصر التفاعل | 3:1 |
| حالة التركيز (Focus) | 3:1 مقابل الجوار |

### النص فوق التعبئات الملوّنة — الخطأ الأكثر شيوعاً
لون الدور الواحد **لا يصلح لدورين**. في الوضع الفاتح تكون التعبئة داكنة فيصلح عليها الأبيض،
وفي الداكن تكون التعبئة فاتحة فينكسر الأبيض تماماً. لذلك لكل دور **زوج**:
```
--sem-danger        لون التعبئة (يقلب مع الوضع)
--sem-danger-on     لون النص فوقها (يقلب معها)
--sem-accent        لون التعبئة
--sem-accent-text   لون النص فوق الأسطح الفاتحة  ← ليس نفس اللون
```
> واقعة حقيقية من هذا المشروع: زر «حذف» بـ `bg-danger text-white` أعطى **2.76:1** في الوضع الداكن،
> وأرقام شبكة الحضور أعطت **2.0:1**. الفحص الآلي هو ما كشفهما، لا العين.

### الفحص الآلي
```bash
npm run test:contrast
```
لا يفحص قائمة tokens مكتوبة يدوياً، بل **يرندر الصفحة فعلياً** في الوضعين ويقيس تباين
كل نص مرئي مقابل الخلفية الحقيقية خلفه (مع دمج الشفافية)، فيكشف أيضاً سوء استخدام لون في مكوّن.
يتجاهل ما هو `aria-hidden` والرموز الملوّنة بذاتها. أي إخفاق يوقف الـ build.

## 13.3 الطباعة (الأهم في منتج عربي)

### الخطوط
```css
--font-ar: "IBM Plex Sans Arabic", "Cairo", system-ui, sans-serif;
--font-en: "Inter", system-ui, -apple-system, sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, monospace;
--font-num: "Inter";   /* الأرقام دائماً لاتينية الشكل للوضوح */
```
- **Subsetting إلزامي:** الخط العربي الكامل +300KB → المجموعة الفرعية ~40KB.
- `font-display: swap` + `preload` للخط الأساسي فقط.
- استضافة ذاتية — لا Google Fonts خارجي (أداء + خصوصية).

### قواعد عربية لا يعرفها معظم المطوّرين
| القاعدة | السبب |
|---------|-------|
| `line-height` للعربية **1.75–1.9** لا 1.5 | التشكيل والنقاط تحتاج مساحة رأسية |
| `letter-spacing: 0` — **ممنوع السالب** | يكسر اتصال الحروف العربية |
| حجم الخط العربي **+1px إلى +2px** عن مقابله اللاتيني | ارتفاع الحرف العربي أقل بصرياً |
| **ممنوع** `text-transform: uppercase` على العربية | لا معنى له ويكسر الشكل |
| **ممنوع** `font-style: italic` على العربية | يشوّه الحروف — استخدم الوزن بدلاً منه |
| الأوزان المستخدمة: 400 · 500 · 600 · 700 فقط | الأوزان الرفيعة تختفي في العربية |
| الأرقام: خيار **عربية (123)** أو **هندية (١٢٣)** لكل مستأجر | تفضيل سوقي يختلف بين مصر والخليج |

### السلّم
```
display  36/44   عناوين الصفحات الرئيسية
h1       30/38   ·  h2  24/32  ·  h3  20/28  ·  h4  18/26
body-lg  17/28   ·  body 15/25 ·  body-sm 13/21
caption  12/18   ·  overline 11/16 (مسافة حروف موجبة للاتيني فقط)
```

## 13.5 RTL / LTR — يُبنى مرة واحدة صح

### الخصائص المنطقية إلزامياً
```css
/* ❌ ممنوع */  margin-left  padding-right  text-align: left  left: 0  border-left
/* ✅ إلزامي */ margin-inline-start  padding-inline-end  text-align: start
                inset-inline-start: 0  border-inline-start
```
في Tailwind: `ms-4 me-2 ps-3 pe-3 start-0 end-0 text-start text-end` — و**قاعدة ESLint/Stylelint ترفض الاتجاهي**.

### ما ينعكس وما لا ينعكس
| ينعكس ✅ | لا ينعكس ❌ |
|---------|------------|
| التخطيط والأعمدة والقوائم | الأرقام والتواريخ والوقت |
| أسهم التنقّل (التالي/السابق) | أيقونات التشغيل ▶ والصوت |
| شرائط التقدّم | الشعارات والصور |
| ترتيب الجداول | أكواد البرمجة |
| أيقونات الرجوع | الرسوم البيانية الزمنية (تبقى يسار←يمين) |

### الاختبار
كل مكوّن يُلتقط له **٤ لقطات**: عربي‑فاتح · عربي‑داكن · إنجليزي‑فاتح · إنجليزي‑داكن.
اختبار انحدار بصري (Visual Regression) في CI يرفض أي تغيّر غير مقصود.

## 13.5.1 الاستجابة (Responsive) — شرط قبول لا تحسين

### نقاط الكسر
```
base   < 640   موبايل (التصميم يبدأ من هنا: Mobile First)
sm     ≥ 640   موبايل كبير / تابلت رأسي
md     ≥ 768   تابلت
lg     ≥ 1024  لابتوب  ← هنا تظهر الأشرطة الجانبية والأعمدة المتعددة
xl     ≥ 1280  ديسكتوب
2xl    ≥ 1536  شاشات عريضة
```
**العرض المرجعي الأدنى: 320px.** أي شاشة أضيق ليست هدفاً، وأي كسر عند 320 عيب لا استثناء.

### قواعد إلزامية
| # | القاعدة | لماذا |
|---|---------|-------|
| 1 | **صفر تمرير أفقي للصفحة** | `html, body { overflow-x: clip }` والمحتوى العريض يمرّر داخل حاويته هو |
| 2 | **الجداول والمقاييس والأكواد** داخل `overflow-x-auto` | لا تدفع الصفحة |
| 3 | `grid-cols-1` صريحة قبل `lg:grid-cols-[...]` | شبكة بلا أعمدة معرّفة تأخذ `max-content` وتكسر الصفحة — وقعنا فيها فعلاً |
| 4 | `min-w-0` على أي عمود شبكة يحوي نصاً أو جدولاً | يمنع تمدّد الابن فوق العمود |
| 5 | **الشريط الجانبي يصير شريط رقائق أفقياً** تحت `lg` | لا قائمة عمودية تأكل شاشة الموبايل |
| 6 | مساحة اللمس ≥ 40px تحت `@media (pointer: coarse)` | تُفرض بقاعدة CSS عامة لا بفئة على كل عنصر |
| 7 | مساحة اللمس هي **العنصر القابل للنقر** لا الأيقونة | التسمية تحيط بمربّع الاختيار فتصير هي الهدف |
| 8 | صور بأبعاد صريحة | يمنع CLS |
| 9 | العنوان الرئيسي يتقلّص: `text-2xl sm:text-3xl` | 36px على 320px تكسر السطر |
| 10 | لا `100vh` لأقسام المحتوى | شريط المتصفح في الموبايل يقتطع منها |

### الفحص الآلي
```bash
npm run test:responsive
```
يفتح كل صفحة على **6 مقاسات** (320 · 375 · 430 · 768 · 1024 · 1440) وباللغتين، ويفشل عند:
تمرير أفقي · عنصر يتجاوز حدود الشاشة · هدف لمس أصغر من 32px على الأجهزة اللمسية.

## 13.7 الأنماط (Patterns) — تُوحّد التجربة

| النمط | القاعدة الموحّدة |
|-------|------------------|
| **صفحة قائمة** | PageHeader (عنوان + إجراء رئيسي) → فلاتر → جدول → ترقيم. نفس الترتيب في **كل** الشاشات |
| **صفحة تفاصيل** | PageHeader مع فتات خبز → تبويبات → محتوى → إجراءات ثابتة أسفل |
| **نموذج** | حقول مجمّعة في أقسام · التحقق عند مغادرة الحقل · حفظ ثابت أسفل · تحذير عند المغادرة بتغييرات |
| **الحالة الفارغة** | أيقونة + عنوان + شرح سطر + زر الإجراء الأول. **إلزامية لكل قائمة** |
| **التحميل** | Skeleton بنفس شكل المحتوى القادم — **ممنوع** Spinner في منتصف صفحة |
| **الخطأ** | ماذا حدث + لماذا + **ماذا يفعل المستخدم الآن** + زر إعادة المحاولة |
| **الحذف** | ConfirmDialog يذكر اسم العنصر ويطلب تأكيداً للعمليات الخطرة |
| **النجاح** | Toast قصير · ولا نُغلق النموذج قبل تأكيد الخادم |
| **الصلاحيات** | ما لا يملكه المستخدم **يُخفى** لا يُعطّل (إلا لو الإخفاء يربك) |
| **الباقة** | ميزة خارج الباقة تظهر بقفل + شرح + زر ترقية — لا تُخفى (تسويق) |

## 13.8 الحركة (Motion)

```css
--duration-fast: 120ms    /* hover, focus */
--duration-base: 200ms    /* قوائم، تبويبات */
--duration-slow: 320ms    /* نوافذ، أدراج */
--ease-out: cubic-bezier(0.16, 1, 0.3, 1)
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1)
```
- الحركة **وظيفية** فقط: توضّح مصدر العنصر ووجهته. لا زخرفة.
- `prefers-reduced-motion` مدعوم في كل مكوّن (إلزامي).
- ممنوع أي حركة تتجاوز 400ms في مسار عمل متكرر.

## 13.9 الوصولية (WCAG 2.2 AA) — شرط قبول لا رفاهية

```
□ كل عنصر تفاعلي يُوصل إليه بـ Tab وله حالة تركيز مرئية بوضوح
□ Escape يغلق أي طبقة · Enter/Space يفعّل · الأسهم تتنقّل في القوائم
□ حبس التركيز داخل النوافذ والأدراج (Focus Trap)
□ كل أيقونة بلا نص لها aria-label بالعربية والإنجليزية
□ كل صورة لها alt (أو alt="" للزخرفية)
□ الأخطاء مرتبطة بحقولها عبر aria-describedby
□ تغيّرات الحالة تُعلن عبر aria-live
□ مساحة اللمس ≥ 44×44px
□ لا يُعتمد على اللون وحده لنقل معلومة (يُضاف رمز أو نص)
□ ترتيب العناوين h1→h6 منطقي
□ يعمل بالكامل عند تكبير 200%
□ الأسهم في RTL تعمل معكوسة بشكل صحيح
```

## 13.10 الثيمات لكل مستأجر

```
themes/
  solo-academy/      marketplace/      center/      hybrid/
    theme.json       ← الاسم · الصورة · الأنماط المدعومة · schema الإعدادات
    tokens.css       ← إعادة تعريف الطبقة الدلالية فقط
    views/           ← تجاوزات Blade (اختيارية)
    preview.png
```

### ما يستطيع المستأجر تغييره من لوحته (بدون كود)
اللون الأساسي (منتقي ألوان يولّد المقياس كاملاً تلقائياً) · لون التمييز · الخط العربي (٤ خيارات) ·
الخط اللاتيني · نصف قطر الحواف (حاد/متوسط/دائري) · الكثافة (مريح/مضغوط) ·
شكل الرأس (٤ أنماط) · شكل التذييل (٣) · الوضع الافتراضي (فاتح/داكن/تلقائي) · الشعار والأيقونة ·
نظام الأرقام · **CSS مخصّص** (باقة متقدمة)

### الضمانة
مهما غيّر المستأجر، **يستحيل** أن ينكسر التباين أو المحاذاة أو الاتساق — لأن التغيير محصور في الطبقة الدلالية، ومنتقي الألوان يولّد درجات مضبوطة التباين آلياً.
