# 16 — وحدة إدارة السنتر التعليمي

> هذه الوحدة هي **أكبر فارق تنافسي** في المنتج: منافسو الكورسات الأونلاين لا يفهمون السنتر،
> وأنظمة السناتر لا تعرف بيع الكورسات. نحن نجمعهما في نظام واحد بقاعدة طلاب واحدة.

---

## 16.1 الفكرة الأساسية: طالب واحد، سجل واحد

```
                        الطالب: يوسف حمدي
                                │
        ┌───────────────┬───────┴────────┬────────────────┐
        ▼               ▼                ▼                ▼
   مجموعة حضورية    كورس مسجّل      امتحان أونلاين    اشتراك شهري
   فيزياء · سبت 4م  "مراجعة نهائية"  درجة 78%         650 ج.م
   حضور 14/16                                          متأخر 51 يوم
        │               │                │                │
        └───────────────┴────────┬───────┴────────────────┘
                                 ▼
              تقرير شهري واحد ← يصل لولي الأمر بالواتساب
```
لا يوجد منافس عربي أو أجنبي يقدّم هذا الربط اليوم.

## 16.3 المجموعات والجداول

```
center_groups
  branch_id · subject_id · grade_id · term_id · teacher_id
  name · capacity · enrolled_count · price · price_type(monthly|per_session|full_term)
  sessions_count · start_date · end_date · status · color · notes

center_schedules            ← الحصة المتكررة
  group_id · room_id · weekday · starts_at · ends_at
  effective_from · effective_to · repeat_rule

center_sessions             ← الحصة الفعلية (تُولَّد من الجدول)
  group_id · room_id · teacher_id · date · starts_at · ends_at
  status(scheduled|running|done|cancelled|postponed)
  topic · notes · attendance_taken_at · online_meeting_id
```

### كشف التعارض (إلزامي — أكثر ما يزعج إدارة السنتر)
عند إنشاء أو تعديل أي حصة، يُفحص فوراً:
```
□ القاعة مشغولة في نفس الوقت؟
□ المدرّس عنده حصة أخرى؟
□ المجموعة عندها حصة أخرى؟
□ عدد الطلاب > سعة القاعة؟
□ الموعد يقع في عطلة رسمية؟
□ الموعد يتعارض مع وقت صلاة (إن فُعّل الخيار)؟
```
النتيجة تظهر **قبل الحفظ** مع اقتراح أقرب موعد بديل متاح.

### تعديلات الجدول
تأجيل حصة · إلغاء · حصة تعويضية · تغيير قاعة · تغيير مدرّس (بديل) — كلها مع **إشعار تلقائي** للطلاب وأولياء الأمور.

## 16.4 الطلاب والتسجيل

```
center_students          ← ملف موسّع مرتبط بـ users
  user_id · code (كود الطالب/الكارنيه) · stage_id · grade_id · school
  birth_date · gender · national_id · address · photo
  guardian_ids(json) · emergency_phone · medical_notes
  source(walk_in|online|referral) · referred_by · joined_at · status

center_enrollments       ← تسجيل الطالب في مجموعة
  student_id · group_id · term_id · price · discount · discount_reason
  starts_at · ends_at · status(active|paused|transferred|dropped)

center_guardians         ← ولي الأمر
  user_id · name · relation · phone · whatsapp · email
  can_login · notification_prefs(json)
guardian_student         ← ربط (ولي أمر واحد لعدة أبناء)
```

**رابط حجز إلكتروني عام:** الطالب يسجّل بنفسه في مجموعة متاحة، ويُحوَّل للدفع مباشرة، ويظهر في قائمة الإدارة للاعتماد.

## 16.5 الحضور — أربع طرق مبنية بالكامل

```
center_attendance
  session_id · student_id
  status(present|absent|late|excused|online)
  method(manual|code|qr|fingerprint|nfc|self|meeting)
  minutes_late · recorded_by · recorded_at · device_id · note
```

| الطريقة | كيف | الاستخدام |
|---------|-----|-----------|
| **يدوي** | كشف على شاشة الجهاز اللوحي | الافتراضي |
| **كود الطالب** | الطالب يقول رقمه/يدخله | سريع |
| **QR** | مسح كارنيه الطالب بكاميرا الجهاز | الأسرع للمجموعات الكبيرة |
| **بصمة / NFC** | جهاز خارجي عبر API أو استيراد ملف | السناتر الكبيرة |
| **تسجيل ذاتي** | الطالب يمسح QR معروضاً على شاشة القاعة (يتغيّر كل 30 ثانية) | يمنع التلاعب |
| **من الاجتماع** | حضور تلقائي من Zoom/Meet/BBB | الحصص الأونلاين |

**حضور المدرّسين** بنفس الآلية — أساس حساب الرواتب والنِسب.

**إشعار فوري لولي الأمر** عند تسجيل الغياب (قابل للتفعيل) — أكثر ميزة يطلبها أولياء الأمور.

```
center_salaries         راتب/مستحق: موظف · نوع(ثابت|بالحصة|نسبة) · فترة · مبلغ
                        خصومات · صافي · حالة الصرف
center_discounts        خصم: طالب · نوع(أخوة|تفوق|حالة|ترويجي) · قيمة · سبب · معتمد
```

### ما يحلّه هذا فعلياً
| المشكلة اليومية | الحل |
|-----------------|------|
| «مين اللي عليه فلوس؟» | لوحة المتأخرات مرتّبة بالمبلغ والمدة، بزر تذكير واتساب جماعي |
| «الفلوس اللي في الدرج مش مظبوطة» | خزنة بحركات مسجّلة + تقفيل يومي + فرق يُبرَّر |
| «المدرّس مستحق كام؟» | نسبة/بالحصة تُحسب آلياً من حضوره الفعلي |
| «الطالب دفع ومحدش سجّل» | إيصال إلزامي مرقّم لكل دفعة + بحث فوري |
| «ولي الأمر بيقول ابنه دفع» | كشف حساب الطالب متاح لولي الأمر لحظياً |

## 16.7 الدرجات والتقييم

```
center_exams            امتحان ورقي أو أونلاين: مجموعة · مادة · نوع · تاريخ
                        درجة كبرى · درجة نجاح · وزن نسبي
center_exam_results     نتيجة: امتحان · طالب · درجة · تقدير · ملاحظة · مصحّح
center_homework         واجب: مجموعة · وصف · موعد · درجة
center_homework_status  حالة تسليم لكل طالب

```
الامتحانات الورقية تُدخَل درجاتها بشاشة إدخال سريع (Excel-like)، والأونلاين تأتي درجاتها آلياً من وحدة الاختبارات.

## 16.8 التقرير الشهري — أهم مخرج للسنتر

يُولَّد آلياً لكل طالب، ويُرسل بواتساب/SMS/بريد ويُطبع PDF:

```
┌───────────────────────────────────────────────┐
│ يوسف حمدي · ثانوية · فيزياء · سبت 4م          │
│ تقرير شهر سبتمبر 2026                          │
├───────────────────────────────────────────────┤
│ الحضور            14 من 16      ▓▓▓▓▓▓▓▓░ 87% │
│ متوسط الدرجات     78%           ▓▓▓▓▓▓▓░░     │
│ الواجبات          9 من 12       ▓▓▓▓▓▓░░░     │
│ الترتيب في المجموعة  7 من 28                   │
│ مقارنة بالشهر الماضي  ▲ 6%                     │
├───────────────────────────────────────────────┤
│ موقف المصروفات    متأخر 650 ج.م               │
│ ملاحظة المدرّس    تحسّن ملحوظ في حل المسائل    │
└───────────────────────────────────────────────┘
```
**إرسال جماعي** لكل أولياء أمور المجموعة بضغطة واحدة، مع تتبّع من فتح الرسالة.

## 16.9 بوابة ولي الأمر

حساب مستقل يرى **كل أبنائه** في شاشة واحدة:
- الحضور والغياب لحظياً · الدرجات · الواجبات · الملاحظات السلوكية
- كشف الحساب والأقساط المستحقة · **الدفع أونلاين مباشرة**
- جدول الحصص القادمة · إشعار عند الإلغاء أو التأجيل
- التواصل مع الإدارة · طلب مقابلة المدرّس
- التقارير الشهرية السابقة

## 16.10 المخزون والعُهد

```
center_items            صنف: اسم · نوع(كتاب|مذكرة|أداة|عهدة) · باركود
                        سعر بيع · تكلفة · حد إعادة الطلب
center_stock            رصيد لكل فرع
center_stock_moves      حركة: وارد · صادر · بيع · تالف · مفقود · تحويل بين فروع
center_custody          عهدة لدى موظف: صنف · كمية · تاريخ · حالة الإرجاع
```
- **بيع المذكرات والكتب من نفس شاشة تحصيل القسط** — أكثر عملية متكررة في السنتر.
- تنبيه تلقائي عند اقتراب النفاد.
- ربط الصنف بكورس أو مجموعة (المذكرة تُباع مع الاشتراك).
- **QR على المذكرة** يفتح فيديو الشرح أو الامتحان (الميزة المأخوذة من Prime E).

## 16.12 التقارير

| التقرير | يجيب على |
|---------|----------|
| المتأخرات | من عليه فلوس؟ كم؟ منذ متى؟ |
| التحصيل اليومي | كم دخل اليوم؟ كاش أم فيزا؟ في أي خزنة؟ |
| الأرباح والمصروفات | صافي ربح الفرع/الشهر |
| إشغال القاعات | أي قاعة فاضية ومتى؟ |
| أداء المدرّسين | حضورهم · نتائج طلابهم · تقييماتهم · مستحقاتهم |
| الغياب المتكرر | من غاب 3 مرات متتالية؟ (تدخّل مبكر) |
| التسرّب | من توقف عن الحضور ولم ينسحب رسمياً؟ |
| الأوائل والمستوى المجمّع | ترتيب الطلاب لكل مجموعة/مادة/مرحلة |
| نمو التسجيلات | من أين يأتي الطلاب؟ (ترشيح · أونلاين · حضوري) |

## 16.13 الربط مع باقي المنصة

| الربط | الفائدة |
|-------|---------|
| المجموعة الحضورية ← كورس مسجّل | الطالب يراجع الحصة التي فاتته |
| الحصة المباشرة ← حضور تلقائي | الغائب حضورياً يحضر أونلاين |
| الامتحان الأونلاين ← درجات السنتر | تصحيح آلي يدخل التقرير الشهري |
| فاتورة السنتر ← بوابة الدفع | ولي الأمر يدفع من بيته |
| المذكرة (منتج مادي) ← المخزون والطلب | بيع وتوصيل |
| أكواد الشحن ← اشتراك المجموعة | توزيع كروت في السنتر لفتح المحتوى الأونلاين |
| شهادة إتمام ← نهاية الترم | تحفيز وتسويق |

## 16.14 اعتبارات تنفيذية

| الاعتبار | القرار |
|---------|--------|
| **الاستخدام في بيئة ضاغطة** | شاشة الحضور والتحصيل يجب أن تعمل بأقل عدد نقرات وبإنترنت ضعيف — **تعمل دون اتصال وتزامن لاحقاً** |
| **جهاز لوحي على مكتب الاستقبال** | تصميم شاشات كبيرة الأزرار مخصّصة للمس |
| **الطباعة** | إيصالات على طابعة حرارية 80mm + تقارير A4 |
| **الأرقام** | الفواتير والإيصالات بترقيم متسلسل غير قابل للتلاعب + سجل تدقيق |
| **الخصوصية** | بيانات القُصّر ← موافقة ولي الأمر + صلاحيات مشدّدة |
| **النسخ الاحتياطي** | يومي — السنتر لا يحتمل فقد يوم تحصيل |
