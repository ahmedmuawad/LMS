## ملاحظات تصميم حرجة
1. **مشغّل الكورس** أهم شاشة في المنصة — تستحق وحدها 4–6 أيام تصميم وتطوير.
2. **محرر المنهج** (سحب وإفلات) و**محرر الصفحات** أعقد شاشتين إدارياً.
3. كل شاشة إدارية تحتاج: بحث + فلاتر + فرز + ترقيم + إجراءات جماعية + تصدير.
4. الموبايل أولاً في كل شاشات الطالب — أغلب المشاهدة من الهاتف.
