## 1) ما تم إنجازه

| المخرج | الحالة |
|--------|--------|
| **التسجيل** يحترم `users.registration_open` — مغلق يعني 404 لا شاشة معطّلة | ✅ |
| حدّ محاولات: 5 تسجيلات لكل IP كل 10 دقائق | ✅ |
| الموافقة على الشروط إلزامية حين `users.terms_required` | ✅ |
| تسجيل **مدرّس**: يُنشئ `Instructor` بـ`approved_at = null`، والدور يبقى `student` حتى الاعتماد | ✅ |
| البريد يُخزَّن بحروف صغيرة دائماً — لا حسابان بفارق حالة حرف | ✅ |
| **تأكيد البريد** برابط موقّع مؤقّت، بلا جدول رموز يُحفَظ ويُبطَل | ✅ |
| رسائل التأكيد والاستعادة تمرّ عبر `notify()` فتستعمل **قالب المشترك المترجَم** لا قالب لارافيل | ✅ |
| حدّ إعادة الإرسال: 3 مرات كل دقيقتين — حماية لسمعة النطاق قبل المستخدم | ✅ |
| **استعادة كلمة المرور**: الردّ واحد سواء وُجد البريد أو لم يوجد — لا كشف للحسابات | ✅ |
| **سياسة كلمة المرور** تُبنى من الإعدادات: الطول الأدنى + حروف/خلط/أرقام/رموز/عدم التسريب | ✅ |
| **التوثيق بخطوتين (TOTP)**: تفعيل بـQR مرسوم محلياً — لا خدمة خارجية ترى السرّ | ✅ |
| السرّ مُعمّى في القاعدة (`Crypt`)، و8 رموز استرداد يُستهلك كلٌّ منها مرة واحدة | ✅ |
| الجلسة **لا تُنشأ قبل اجتياز التحدّي** — تُحفظ نيّة الدخول فقط | ✅ |
| إلزام التوثيق من الإعدادات (`users.two_factor = required`) يمنع الإطفاء | ✅ |
| حدّ 5 محاولات كل 5 دقائق على التحدّي | ✅ |
| **صفحة الحساب**: بيانات، تغيير كلمة مرور (بتجديد الجلسة)، إغلاق الحساب | ✅ |
| البريد **لا يُغيَّر** من صفحة الحساب — تغييره مسار مستقل بتأكيد | ✅ |
| إغلاق الحساب **إغلاق ناعم**: تعطيل وتعمية البريد لا حذف يكسر الطلبات والشهادات | ✅ |
| المالك لا يستطيع إغلاق حسابه — لا مشترك بلا مالك | ✅ |
| الدخول يرفض الحساب غير النشِط قبل إنشاء أي جلسة | ✅ |

## 2) الاختبارات والبوابات

- `tests/Tenancy/RegistrationTest.php` — **22 اختباراً، 72 تأكيداً**.
- المجموعة كاملة: **528 اختباراً · 1577 تأكيداً · كلها ناجحة**.
- بوابة الاستجابة والتباين على **سبع شاشات جديدة** في مقاسين ووضعين:
  `/register` · `/forgot-password` · `/reset-password/{token}` · `/verify-email`
  · `/account` · `/account/two-factor` · `/two-factor`.
- أُضيفت جميعها إلى `.github/workflows/ci.yml`، ومعها أمر
  `demo:two-factor` لأن شاشة التحدّي لا تُفتَح إلا بجلسة معلّقة.

### ما كشفته البوابة

روابط تذييل شاشات المصادقة كانت **أهداف لمس بارتفاع 17px** — سطر نصّ لا زرّ.
عُولجت في الغلاف نفسه لا في كل شاشة، فلا تتكرّر في شاشة تُضاف لاحقاً.
