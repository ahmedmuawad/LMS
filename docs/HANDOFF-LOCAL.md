أنت تكمل بناء **منصّة LMS SaaS متعدّدة المستأجرين** بلارافيل، تحلّ محلّ
موقع ووردبريس/WPLMS. بُنيت في سيشنات سابقة على السحابة، وأنا الآن
أشغّلها **محلّياً على متصفّحي** لأجرّبها بنفسي.

مهمّتك بهذا الترتيب: **شغّلها لوكال** ← **اعمل Audit كامل صادق** ←
**أكمل الباقي حسب الأولوية**.

## قواعد العمل (مُلزِمة)

- **العربية** لغة الحوار، وكل نصوص الواجهة والتعليقات في الكود عربية.
- **الفرع**: `claude/wplms-courses-services-site-06eek0` — لا تدفع لغيره.
- **لا Pull Request** إلا إن طلبتُه صراحةً.
- **لا Filament، ولا إضافات خارجية** للسيو أو المدفوعات — كل شيء داخلي.
- **بلا نسخ مبسّطة**: كل خيار يُبنى كاملاً، ويُحكَم بالإعدادات وبباقة الاشتراك.
- **أهمّ ثلاثة عندي**: ديزاين سيستم موحّد · ريسبونسيف · تباين ألوان
  سليم على الخلفيات الداكنة.
- **المنهجية**: وثّق ← خطّط ومرحِّل ← نفّذ ← راجع بعينك ← راجع بعين
  **مبرمج آخر** وبعين **صاحب المشروع** ← سُدّ الثغرات ← اقفل بتقرير مكتوب.
- **لا تسألني إذناً على كل خطوة** — اشتغل وأخبرني بالنتيجة.
- **لا تدّعِ إنجازاً لم تتحقّق منه حيّاً.** كل ما بُني حتى الآن كُشفت
  عيوبه بالمتصفّح لا بالاختبارات وحدها، فافعل مثله.

## أولاً: التشغيل المحلّي

```sh
composer install
npm ci
cp .env.example .env
php artisan key:generate
touch database/database.sqlite database/testing.sqlite
php artisan migrate --force
npm run build

# مشتركون تجريبيون — كل واحد يمثّل نمطاً مختلفاً
php artisan demo:tenant --fresh                                      # demo   · منصّة متعددة المدرّسين
php artisan demo:tenant --slug=center --mode=center --plan=center --fresh

php artisan demo:math-school --fresh                                 # math   · مدرسة رياضيات
php artisan demo:center-school --fresh                               # sanad  · سنتر تعليمي
php artisan demo:two-factor --slug=demo                              # يفعّل 2FA لحساب تجريبي
php artisan super-admin:create --name="المشرف" --email=admin@platform.test --password=<اختر>

php artisan serve --host=127.0.0.1 --port=8000
```

127.0.0.1 center.localhost
127.0.0.1 fresh.localhost

## ملاحظات تقنية تختصر عليك الوقت

هذه أخطاء وقعنا فيها فعلاً — لا تكرّرها:

- **`config()` تقسم المفاتيح على النقطة**: `config('a.b.c')` لا تقرأ
  مفتاحاً حرفياً اسمه `b.c`. اقرأه مصفوفةً: `config('a.b', [])['c']`.
  هذا الخطأ عطّل نظام النقاط والشارات كلّه **صامتاً**.
- **النصّ ذو العلامة الواحدة في PHP يبتلع `\`**: صياغة TeX مليئة
  بالشرطات المائلة، و`'a\\c'` تصير `a\c`. استعمل `implode("\n", [...])`
  بعلامات مفردة، أو ضاعف الشرطات.
- **الحقل المترجَم**: `getAttribute` عليه يُعيد **نصّ لغة العرض** لا
  المصفوفة. استعمل `getTranslations()` في شاشات التحرير — الخلط بينهما
  كان يمحو العناوين بلغاتها عند الحفظ.
- **`{{ trim($slot) }}` في مكوّن Blade يُهرِّب مرتين**: التحويل إلى نصّ
  يُفقد `Htmlable`. اطبع `{{ $slot }}`.
- **RTL والمعادلات**: `.katex` ترث اتجاه الصفحة فتنعكس. عُولجت بـ
  `direction: ltr; unicode-bidi: isolate` في `resources/js/math.css`.
- العربية تحتاج مدى صريحاً في `trans_choice`: `{1}…|{2}…|[3,10]…|[11,*]…`.
- اختبارات `tests/Tenancy` لا تستخدم `RefreshDatabase` — تبديل سياق
  المشترك يعيد اتصال القاعدة فتضيع المعاملة. تُهاجَر من الصفر لكل اختبار.
- **الديزاين سيستم ثلاث طبقات**: أوّليّة `--c-*` ← دلاليّة `--sem-*` ←
  `@theme inline`. **لا تكتب لوناً حرفياً في Blade.**
- **الصلاحية تفتح الشاشة، وحصر النطاق يحدّد ما فيها** — وبغير الثاني
  تصير الأولى بلا معنى. الملفات: `Ability` (قائمة مغلقة) ·
  `config/roles.php` (المصفوفة) · `Scope` (حصر الصفوف).
- **قائمة اللوحة تشتقّ صلاحية كل عنصر من حارس مساره** — فلا تضف عنصراً
  لشاشة غير موجودة: اختبار «لا رابط مكسور» يفشل على أول 404.
- **هدف اللمس ≥ 32px** وإلا فشلت بوابة الاستجابة. مربّعات الاختيار
  والروابط في التذييل كانت 17–29px.
- بعد إضافة أي ملف Blade جديد: **`npm run build`** وإلا لم تُولَّد فئات
  Tailwind الجديدة فتبدو الشاشة مكسورة بلا سبب ظاهر.
